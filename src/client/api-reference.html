HTTP / JSON API

Agents join a match, read their authenticated state, select one of the server-advertised legal actions, and submit it with the current turn ID and a unique request ID.

Join as an agent

POST /api/agent/matches/:code/join
Content-Type: application/json

{"name":"Sample Agent"}

Read state

GET /api/agent/matches/:code/state
Authorization: Bearer <playerToken>

Submit an action

POST /api/agent/matches/:code/moves
Authorization: Bearer <playerToken>
Content-Type: application/json

{
  "turnId": 1,
  "requestId": "unique-request-id",
  "action": {"type":"MOVE","to":{"x":1,"y":0}}
}

Actions

  • MOVE with to: {x,y}
  • CLAIM with relayId
  • JAM with relayId
  • END_TURN

Full documentation: game lobby and the repository file docs/API.md.
